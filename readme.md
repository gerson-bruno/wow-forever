## ⚔️ Sobre o Projeto

O **WoW Forever** traz uma roupagem *Classic Plus* para o universo de Azeroth, expandindo combinações clássicas e introduzindo novas raças (como os *Skyborne*) e novas árvores de classes. Este projeto nasceu para servir como um hub rápido, elegante e responsivo para os jogadores consultarem o meta, as regras de classes por raça e as especificações técnicas de cada combatente.

---

## ✨ Funcionalidades Principais

* **Trilha Sonora Imersiva:** Player de áudio integrado com trilhas clássicas e controle dinâmico de volume.
* **Seletor de Raças por Facção:** Alterne entre *Aliança*, *Horda* e a raça neutra *Skyborne* para visualizar instantaneamente as combinações de classes liberadas no ecossistema *Forever*.
* **Grimório de Classes Interativo:** Cards detalhados para cada classe com ícones oficiais clássicos.
* **Modals UX-Friendly:** Ao clicar em qualquer classe, abre-se uma janela detalhada contendo:
  * Papel principal no grupo (Tanque, DPS, Curandeiro).
  * Índice de dificuldade em tempo real (sistema de estrelas de 1 a 5).
  * Descrição aprofundada da lore e mecânicas.
  * Explicação detalhada de cada especialização (Specs).
  * Layout otimizado com scroll fluido no texto e **imagem fixa em alta definição** à direita.
